# CLI Todo App in Go

A persistent CRUD-based CLI todo application built using Go.

## Features

- Add todos
- List todos
- Mark todos as completed
- Delete todos
- Persistent JSON storage

## Commands

### Add Todo

```bash
go run . add "Learn Go"

### List Todo

```bash
go run . list

### Mark Todo Completed

```bash
go run . done 1

### Delete Todo

```bash
go run . delete 1
